# MAGI Current Season Definition

Date: 2026-09-08 JST
Status: CONFIRMED

## Formal definition

For baseball statistics in MAGI, `今期` / `今季` means the current 2026-2027 new-team season beginning with the first recorded game on **2026-08-02**.

- Start date for statistical aggregation: **2026-08-02**
- Scope: new-team 2026-2027 game statistics from that date forward
- Activity-start date is not used for statistics; the first recorded game is the boundary

## Interpretation examples

- `今季OPS` -> statistics from 2026-08-02 onward
- `今期防御率` -> pitching statistics from 2026-08-02 onward
- `通算` -> do not substitute current-season values; use the relevant all-time/career aggregation explicitly

This definition was confirmed by the project owner and should be used consistently in future routing, retrieval, and answer-quality tests.
