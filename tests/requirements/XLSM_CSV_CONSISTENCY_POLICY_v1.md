# MAGI XLSM / CSV 整合性ポリシー v1

Date: 2026-09-09

## 正本原則
- `00_MASTER_正本` の XLSM をシーズン通算数値の唯一の正本とする。
- `10_DETAIL_詳細データ` の CSV は試合別・条件別・守備・走塁等の詳細分析用の副次ソースとする。
- CSVの値でXLSMを上書きしない。平均・折衷もしない。

## 照合ルール
打撃CSVを分析に使う前に、CSVを選手・対象期間で集計し、XLSMと共通するカウント項目を照合する。

対象: 打数、安打、打点、得点、単打、二塁打、三塁打、本塁打、三振、四球、死球、盗塁、盗塁刺、犠打、犠飛。

- 一致: CSV詳細分析を許可。
- 不一致: XLSMを正しい値として採用し、その選手/期間のCSV詳細分析を停止する。MAGIは矛盾したCSV数値を回答に出さない。
- XLSMに存在しないCSV専用項目は、整合性ゲート通過後のみ詳細分析に利用する。

## 率の扱い
AVG / OBP / SLG / OPS / 盗塁成功率などの率はCSV記載率を正解として比較しない。丸め誤差を避けるため、正本XLSMのカウント値または整合性確認済みのカウント値から再計算する。

## 守備CSV
守備CSVは守備機会、補殺、刺殺、失策、併殺、捕逸、許盗塁、盗塁企図、盗塁阻止、牽制刺などの詳細分析に使用する。XLSMに同一項目が存在する場合は必ずXLSMと照合し、矛盾時はXLSMを優先してCSV分析を停止する。XLSMに対応項目がない場合でも、対象シーズン・選手・試合の重複/期間整合性を確認してから使用する。

## 現/旧チーム
この規則は `2026-2027_CURRENT_現チーム` と `2025-2026_ARCHIVE_旧チーム` の双方に同じように適用する。
