# MAGI Numeric Evidence Guard

For 2026-2027 player batting claims, explicit current-season values in the Evidence snapshot/comparison are authoritative.

Rules:
- Never invent or infer a batting-average band (for example `0割台`) that conflicts with the explicit current AVG.
- When a statement evaluates strikeouts, prefer the explicit AB and SO counts when they are available.
- Current-season numeric claims must not be derived from one recent game when a season aggregate exists.
- Historical 2025-2026 values remain reference evidence and must not overwrite 2026-2027 current values.
