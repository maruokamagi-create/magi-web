# MAGI-WEB 守備ポジション別記録仕様 v1

制定日: 2026-09-10

## 方針

守備のポジション別成績は、推測で過去データを分解しない。

現時点の正式表示は以下までとする。
- 選手総合守備成績
- 相手校別守備成績

過去記録に守備位置ごとの詳細がない場合、打順・先発守備位置・選手プロフィール等から刺殺、補殺、失策などを割り振らない。

## 今後の記録開始ルール

守備詳細データに `守備位置` 列を追加する。

1試合の中で守備位置が変わった場合は、同じ選手でも守備位置ごとに行を分ける。

例:

| 選手名 | 相手校 | 守備位置 | 守備イニング | 守備機会 | 刺殺 | 補殺 | 失策 |
| --- | --- | --- | ---: | ---: | ---: | ---: | ---: |
| 大野 竜暉 | 坂井中 | 捕手 | 4.0 | 5 | 4 | 1 | 0 |
| 大野 竜暉 | 坂井中 | 投手 | 2.0 | 2 | 0 | 2 | 0 |

## 守備位置の標準値

- 投手
- 捕手
- 一塁
- 二塁
- 三塁
- 遊撃
- 左翼
- 中堅
- 右翼

略記を入力する場合でも、MAGI-WEB側では上記の正式名称へ正規化して扱う。

## 推奨追加列

必須:
- 選手名
- 相手校
- 守備位置

推奨:
- 試合日
- 試合ID
- 守備イニング
- 守備機会
- 刺殺
- 補殺
- 失策
- 併殺
- 三重殺
- 捕逸
- 許盗塁
- 盗塁企図
- 盗塁阻止
- 牽制刺
- 捕妨害

## 集計ルール

ポジション別守備率 = (刺殺 + 補殺) / (刺殺 + 補殺 + 失策)

捕手の盗塁阻止率 = 盗塁阻止 / 盗塁企図

同一選手・同一ポジションの複数行は合算する。

相手校別とポジション別は交差集計可能にする。

例:
- 大野 竜暉 / 捕手 / 全試合
- 大野 竜暉 / 投手 / 全試合
- 大野 竜暉 / 捕手 / 坂井中戦
- 大野 竜暉 / 投手 / 坂井中戦

## MAGI-WEB表示ルール

ポジション別の根拠データが存在しない期間は、ポジション別数値を表示しない。

将来、`守備位置` を含む十分な詳細データが蓄積された時点で、守備レポートに次の順で追加する。

1. 総合守備成績
2. 相手校別守備成績
3. ポジション別守備成績
4. 相手校 × ポジション別守備成績

## 禁止事項

- 先発守備位置だけを根拠に試合全体の守備成績をその位置へ割り当てない。
- 選手プロフィールの主ポジションから過去成績を推定しない。
- 捕手回数だけを使って他ポジションの守備機会を逆算しない。
- 推測値を正式成績として表示しない。

MAGIの原則: 記録がないものは「不明」とし、推測で埋めない。
